# تعريب No Rest for the Wicked

مشروع تعريب لعبة **No Rest for the Wicked** إلى اللغة العربية الفصحى.

---

## محتويات المستودع

* **`translations/`**: ملفات نصوص اللعبة بصيغة CSV (ترميز UTF-8 with BOM).
* **`glossaries/`**: معاجم المصطلحات المعتمدة لأسماء الشخصيات، المناطق، والقدرات.
* **`scripts/`**: أدوات التحقق من سلامة الأكواد والوسوم.

---

## المساهمة

نرحب بمساهمات الجميع لمراجعة وتحسين النصوص عبر إرسال **Pull Request**.

عند التعديل يرجى التأكد من:
1. الحفاظ على الوسوم والمتغيرات مثل `{0}` و`<color>...</color>` كما هي دون تغيير.
2. استخدام المصطلحات المعتمدة في مجلد `glossaries/`.
3. التحقق من سلامة الملفات قبل الإرسال:
   ```bash
   python3 scripts/validate_placeholders.py translations/<اسم_الملف>.csv
   ```
